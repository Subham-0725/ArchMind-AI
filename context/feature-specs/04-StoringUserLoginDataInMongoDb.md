# Login User MongoDB Integration

## Task

Store authenticated user data in MongoDB and retrieve it when the user logs in.

## Requirements

1. Create a **User model** in the backend.
2. Define required user fields and validation rules.
3. Store user data in **MongoDB** after successful login.
4. Check whether the user already exists before creating a new record.
5. Update existing user data when required.
6. Retrieve user data from MongoDB after successful login.
7. Create backend **API endpoints** for user creation and retrieval.
8. Return only the required user data to the frontend.
9. Handle missing users and database errors properly.
10. Keep sensitive user information secure and never expose credentials.
11. Connect the login flow with the MongoDB user APIs.
12. Maintain consistent user identification across login sessions.
13. Add proper request validation and error handling.
14. Test **new user**, **existing user**, and **failed login** cases.
15. Ensure existing authentication and frontend functionality remain unaffected.
